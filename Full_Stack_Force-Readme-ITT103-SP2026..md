POS System
    This project is a simple Point of Sale (POS) system created in Python. It allows a user to add and remove items from a cart, view their cart, and checkout with tax and discount calculations.
The program allows users to:
    Add items to the cart with stock checking,
    Remove items from the cart and return them to inventory,
    View items in their cart,
    Checkout with automatic tax (10%) and discount (12% over $5000) and,
    Enter payment and receive change.
    The system also prevents the user from entering invalid inputs and gives feedback when something is wrong.
In  this project we used:
    Loops (used to go through items and keep the program running)
    Decision making (if, while, match-case)
    Variables for storing totals, quantities, and prices
    User input & validation using try/except
    Lists and dictionaries to store inventory and cart data
The program also includes error handling to prevent crashes. For example:
    Only numbers are accepted where needed
    Users cannot add more items than available
    Payment must be enough before checkout completes
    Overall, this project meets the assignment requirements and demonstrates my understanding of Python basics, problem-solving, and program structure. It works as expected and shows how programming can be used to simulate a real retail system.
